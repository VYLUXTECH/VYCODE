Setup on Android (Termux)

    
# Install Termux from F-Droid (not Play Store)
pkg update && pkg install git nodejs

# Clone VYCODE
git clone https://github.com/VYLUXTECH/VYCODE.git
cd VYCODE/deepseek-proxy

# Install and start
npm install
node server.js

  


  

    
Setup on PC / Mac

    
# Install Node.js from nodejs.org, then:
git clone https://github.com/VYLUXTECH/VYCODE.git
cd VYCODE/deepseek-proxy
npm install
node server.js
